Production-Grade Coder · Atomic Redis Lua + Complexity

Complexity: Time O(1), Space O(1) (~96 bytes per active client key in Redis hash → 1M concurrent keys ≈ 96 MB RAM). Rejected Alternatives: Naive GET → INCR (race condition under concurrent bursts); Sliding Window Log (O(N) memory per key, blows up under high-QPS tenants).

-- Atomic Redis Lua Token Bucket (single-threaded execution eliminates TOCTOU races)
local key        = KEYS[1]
local cap        = tonumber(ARGV[1])
local rate       = tonumber(ARGV[2])
local now        = tonumber(ARGV[3])
local cost       = tonumber(ARGV[4])
local b          = redis.call('HMGET', key, 'tokens', 'ts')
local tokens     = tonumber(b[1]) or cap
local ts         = tonumber(b[2]) or now
tokens           = math.min(cap, tokens + math.max(0, now - ts) * rate)
local allowed    = 0
if tokens >= cost then tokens = tokens - cost; allowed = 1 end
redis.call('HMSET', key, 'tokens', tokens, 'ts', now)
redis.call('EXPIRE', key, math.ceil((cap / rate) * 2))
local retry      = allowed == 1 and 0 or math.ceil((cost - tokens) / rate)
return {allowed, math.floor(tokens), retry}
Concurrency & Failure

Choose explicit fail-open (public read APIs) vs fail-closed (/v1/auth/login, payment endpoints) if Redis times out (>15 ms). Use local edge token-leasing batches for >100k QPS global POPs.

Observability & Supply Chain

Emit structured OTel metrics (ratelimit.decisions{route,status,threat}) without logging raw IP/API-key secrets; alert on sudden 429 ratio spikes (>5% over 5m).

Enterprise Product Manager · Trade-Offs, Multi-Tenancy & FinOps

Critical Edge Cases
  • Retry Storm (Metastable Failure): Without Retry-After + full client jitter, 10k throttled SDKs retry in lockstep and collapse origin gateways.
  • Noisy Neighbor Tenant: Combine global gateway cap + per-tenant tier quota + shuffle-sharded Redis shards so one enterprise whale cannot starve free users.
  • Clock Skew: Use Redis server TIME (not gateway wall clocks) inside Lua scripts.
Unit Economics (Base vs 10x) [Illustrative]
  • 10k req/s: Single Redis primary + replica (~$60–$120/mo) handles >80k Lua ops/sec.
  • 100k+ req/s (10x): Cloudflare Durable Objects / Edge local quota leasing drops central Redis RPCs by 90%, keeping cost sub-linear.
